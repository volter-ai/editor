Volter Model Editor

Open source · macOS on Apple Silicon

Blender, driven by your coding agent

Blender 5.2, compiled to WebAssembly, inside an editor your coding agent can drive. Ask for a model; the agent builds it through Blender's own Python, photographs it, and every edit saves to the project's .blend.

npx @volter/model-editor create my-models

Node.js 24 on macOS with Apple Silicon. The command makes the project, installs the editor once, and opens it.

Blender itself

Not a lookalike: Blender 5.2 built for the browser from its public source, the same bpy your scripts already use.

Your agent

The Chat pane runs the coding agent you already use — Claude Code, Codex and others. Through Blender's Python and MCP it inspects, edits and photographs the model.

A real .blend

Every edit saves to the project's .blend and survives reopening.

Today

  • macOS on Apple Silicon. Windows and Linux come later.
  • Rendering is not yet at parity with Blender's Cycles.
  • Open source: the editor under AGPL-3.0, Blender under the GPL. Licenses and notices are in the repository.
