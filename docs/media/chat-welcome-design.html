Behavior

  • Zero ready → welcome. The welcome shows only while no agent is both installed and signed in. The composer stays in place, disabled, reading Sign in to start a chat.
  • One ready → chat. With exactly one agent signed in, Chat opens straight to an empty chat on that agent. No welcome, no picker.
  • Two or more → last used. Chat opens on the agent used last; the others are one step away in New chat (frame 6), which lists every agent, signed in or not.
  • Button states. Sign in → Installing (only when the agent is missing) → Waiting for the browser → signed in. While busy the button is disabled with a spinner and the view's progress bar runs; the other provider's button stays usable. The line under each button is one status slot (caption → Cancel → error), so nothing below it moves.
  • Not installed → install, then sign in. The same button installs the agent from its vendor's official package (Codex from OpenAI, Claude Code from Anthropic), then goes straight into that agent's own sign-in, which opens ChatGPT or Claude in the default browser. One click. Codex runs in this Chat; nothing opens a second chat panel.
  • Cancel and failure. Cancel stops the pending sign-in and returns the button to Sign in with ChatGPT with its caption, no error. If install or sign-in ends without a signed-in account, the slot shows Sign-in didn't finish. and the button reads Try again; the full reason goes to the Chat output log, not the welcome.
  • Live detection replaces "Check again". Cyclotron watches each agent's sign-in state continuously, including sign-ins made outside Cyclotron (for example in a terminal). The moment one lands, the welcome is replaced by an empty chat (frame 5), the composer takes focus, and Signed in with ChatGPT shows until the first message is sent.
  • Picker. Choosing a signed-in agent starts a new chat with it. Choosing a Sign in with … row runs the same install-and-sign-in flow, with its progress in the Chat panel. The "model and reasoning…" rows open that agent's model and reasoning-effort choices. Signing out of every agent brings the welcome back.
