# Roadmap — First Person Arena

Write this roadmap carefully before writing game code. Start with one task for
the complete playable prototype described by the brief—not one task per
mechanic, subsystem, implementation layer, test, or minor improvement. That
prototype task includes the full core loop, game-owned autoplay, and gameplay
analytics/readouts that demonstrate the loop works. Add another task only for a
later game feature of comparable scope.

Each task has one lifecycle status and one `Summary:` description. Do not add
acceptance criteria yet. `ztrack check` verifies the structure and warns while
this configured roadmap is empty.
